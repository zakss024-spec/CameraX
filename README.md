# NinjaCam

Starter Android camera project using Kotlin + CameraX.

Build:
1. Upload this project to a GitHub repository.
2. Open Actions.
3. Run "Build NinjaCam APK" (or push to main).
4. Download the `NinjaCam-debug` artifact.

This is the 0.1 foundation. Astro mode, video capture, lens detection,
smooth zoom, and advanced controls will be added in later versions.
